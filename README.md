# Harness² Lab — Interactive Engineering Guide

An interactive, hands-on learning resource for understanding **Harness²**, its recursive harness-improvement approach, and the engineering principles behind it.

🌐 **[Explore the live guide](https://kannu-prieya.github.io/harness2-guide/)**

---

## What is Harness²?

Harness² explores how an AI agent can improve not only the task it performs, but also the harness responsible for executing that task.

The central idea is to create a recursive improvement loop: use experience from execution to propose, test, and refine the harness itself.

This guide breaks down the concepts, architecture, experimental approach, and practical engineering implications of Harness².

## What's inside?

The interactive guide is organized into four sections:

### 1. Learning Guide

Ten structured lessons covering:

- Why Harness² exists
- The two harnesses: execution and improvement
- Propose–Probe–Compose
- Parallel vs. sequential recursion
- Experience libraries and learning across tasks
- The eight editable harness components
- Evidence-driven harness improvements
- Experimental results and limitations
- Exploring the Harness² repository

### 2. Practice Tasks

Five hands-on exercises to connect the research concepts with practical engineering:

- Build a baseline harness and record a trajectory.
- Run a manual Propose–Probe–Compose experiment.
- Create an experience library for future tasks.
- Compare parallel and sequential refinement.
- Map Harness² concepts to an incident root-cause agent.

### 3. Production-readiness Checklist

A practical checklist covering:

- Baselines and reproducibility
- Isolation and permissions
- Evidence for edits
- Artifact validation
- Regression testing
- Runtime budgets
- Promotion and rollback
- Secrets and untrusted code

### 4. Key Takeaways

A concise summary of the most important ideas and engineering implications.
